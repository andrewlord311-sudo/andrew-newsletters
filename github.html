Five open-source projects, picked for you rather than for the crowd. I searched GitHub by topic across music, Obsidian, video, games and puzzles, looked closely at six finalists (and glanced at a few more), and kept five. Every pick is more than a month old, has a stated licence, and comes with a plain line about what could go wrong. I did not download or run any of it: this is what the project says about itself, checked against who maintains it and how active it is.

Try this weekend

Three things you can try in under an hour each.

NoteLite

Scan printed music into editable scores · Mac, Windows, Linux

What it is. Open-source sheet-music recognition. Give it a PDF or photo of printed music and it produces a score you can correct, then export as MusicXML or MIDI, or practise against with a MIDI keyboard or microphone. It is built on Audiveris, the long-standing open-source recognition engine.

Why it is for you. You study scores. This turns an IMSLP PDF into something you can hear and edit: play back a quartet you are reading, or pull a passage into your own notation software. It is the kind of thing paid scanners charge for.

To try it. Download a desktop package from the Releases page (Java-based; macOS 13+ has a native build), or build from source with Java 21. Try one page of a score you know well and see how many notes it gets wrong. About 30 minutes. The iPad and iPhone versions are development builds only, with no App Store release, so treat this as a Mac and PC tool.

Risk. Two people maintain it, but it is very active (at least 100 commits in the last month, release 5.13.0 on 23 September). The licence is mixed: the repo is MIT, but the files derived from Audiveris keep their AGPL-3.0 licence, which the README says openly. Fine to use for yourself; read it before building anything on top. Check the release notes before running an installer.

ComposeYogi

A music maker in the browser · works on the iPad

What it is. A free, open-source, Ableton-style composer that runs entirely in the browser: beat-making, loops and arrangements, built on Web Audio. It saves locally in the browser, works offline once installed, and exports WAV, MP3, MIDI or a project file.

Why it is for you. Nothing to install, so it is the quickest thing in this issue to try, and it suits the iPad you sketch on. It is also a real-world example of a large Web Audio app, relevant to the games you build.

To try it. Open the live demo at composeyogi.com, add it to the iPad home screen, and make a short loop. Then export it as MIDI and open the file in your notation software to see how clean the notes are. About 20 minutes.

Risk. One developer, and development has slowed (two commits in the last month; release 1.4.0 on 31 August). Supported through Patreon. It runs locally and the README does not mention an account or tracking, but as a single-person project, do not rely on it for work you cannot lose: export your files.

Synch

End-to-end encrypted sync for Obsidian vaults · Mac, iPad, Android

What it is. An Obsidian community plugin that encrypts your vault on the device before uploading it, then syncs it to your other devices. You can use its hosted service (a free plan and a paid one) or deploy your own server to your own Cloudflare account. It merges simple edits to Markdown files automatically and keeps both versions when edits clash.

Why it is for you. Your two vaults each have a sync problem: the Second Brain lives in iCloud, which your Android phone cannot see, and the family vault depends on git with phones that only pull. This is a possible way to put the same vault on all your devices. It also fits what you already run, since you use Cloudflare.

To try it. Do not point it at either real vault yet. Copy a small test vault, install the plugin from Obsidian's community plugins, and sync it between the Mac and the Android phone. Self-hosting on Cloudflare is the longer route; the hosted free plan is the quick one. About an hour.

Risk. Still version 0.5 (0.5.5 on 6 October), so expect rough edges. Nine contributors and 48 commits in the last month is a healthy sign. The README itself says to back up your vault before changing sync provider, and running it alongside iCloud or git on the same vault would cause conflicts. The hosted option puts (encrypted) copies of your notes on their servers.

For your projects

Something to learn from rather than install.

HyperFrames

Write HTML, render video · by HeyGen

What it is. An open-source framework that turns HTML, CSS and animations into repeatable MP4 videos. You can use it from a command line or from Claude Code through a plugin and a set of skills, and it has a native Mac app.

Why it is for you. It is the same idea as the video pipeline you built for Music Nuggets and the kids' videos (HTML scenes recorded in a browser, then joined with ffmpeg). Read how it makes rendering repeatable and how its skills structure the loop of plan, write, lint, preview, render. The point is to learn from it, not to replace your pipeline.

To try it. Start by reading its documentation (about 20 minutes) and looking at the showcase. If you want to try it, it needs Node 22 or later, and it installs through npx, which downloads and runs code from the npm registry: skim what it installs before you run it, and try it in a scratch folder rather than in your pipeline folder.

Risk. Backed by a real company (HeyGen), with at least 100 contributors, daily releases (v0.8.172 landed today) and 369 open issues. It moves fast, so expect things to change under you. Its 66,000 stars are far more than I would trust on their own, but the 6,000 forks, the contributor count and the release history all support that it is real.

A game

Chogan

A small collection of finishable games · browser, Android, iPad home screen

What it is. A free, open-source app of games you can finish in one sitting: tower defence (six fixed maps plus a daily map, twenty waves and an endless mode), sudoku with a daily challenge, minesweeper and dots and boxes. No ads, no purchases and no tracking, and it works offline.

Why it is for you. You like tower games and sudoku, and this is both in one small package. It runs as a web page you can add to the iPad home screen, and it is on F-Droid for the Android phone.

To try it. Open choganhq.github.io/chogan in a browser and play a sudoku and a tower-defence map. About 15 minutes. It also reads as a good model of a minimal, no-tracker games app.

Risk. Small and young: 80 stars, three contributors, created 5 September 2026 (about six weeks old), and version 0.9.0, released today after several releases in one day. That is just over the one-month line, so this is a trial, not a keeper. The F-Droid build is reproducible, which is a good sign for the Android version. The README is in English and Farsi.

What I left out, and why

The filter, shown working. The rules are in scope/github.md.

  • Unofficial ports and compatibility layers for commercial games, including one that tops this week's list of new repositories. Copyright-grey, and you would be running binaries nobody has vetted. (Rule 3.)
  • An adult-content prompt pack and a clone of a company's branded interface. (Rule 3.)
  • Repositories with 100,000+ stars that are a few months old. I could not tell real interest from bought stars, so I passed unless forks, contributors and releases backed the number up. (Rule 6.) HyperFrames is the one that did.
  • Everything created in the last month, however well starred. (Rule 1.)
How I checked each pick Age, licence, who owns it, number of contributors, commits in the last 30 days, releases, and a read of the README for warning signs (installs that pipe a script into your shell, accounts, telemetry, subscriptions). Stars came last, because they are the easiest number to fake.
