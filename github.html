Box Pleating Studio

Origami design, blueprinted in a browser · Mac, iPad

What it is. A design tool for box-pleated origami. You describe the model you want as a tree of flaps and it works out the crease pattern, including the stretched gadgets that complex designs need — Kamiya-style patterns and GOPS among them. It is a TypeScript web app, used from a page rather than installed.

Why it is for you. Your origami notes carry an open question about what software exists for designing folds rather than following someone else's diagram, and it is the one corner of your range this newsletter has never had anything for. Last week it had to throw out the nearest candidate because the repository had no licence at all. This is the licensed answer, and it is the serious one: it is nearly six years old and still being committed to this month. It also sits exactly where the folding meets the geometry you have been working out by hand — the 72-36-18 business, approximating sevenths — because a crease pattern is that arithmetic made visible. Being a web app, it is also one of the few things here that works where the sketching actually happens.

To try it. Open the project site, launch the app, and build a two- or three-flap tree so you can read the crease pattern it gives back against something you could actually fold. Nothing to install, no account, and the README offers no install commands at all — it points at the site and a user manual. About 30 minutes.

Risk. MIT by GitHub's reading of the repository, though the README only shows a licence badge and never names one in text. The shape is good for a tool like this: created December 2020, committed to this month, which matters more for geometry software than any star count. The numbers are small — 95 stars, 8 forks, and it reads as a one- or two-person project. Two honest caveats. The README says nothing about devices, offline use or browsers; the only platform claim anywhere is a badge reading platform: ALL, which is a badge and not a promise, so the iPad here is inference from it being a web app rather than something anyone has told you. And the site's "Launch App" button goes to bpstudio.abstreamace.com, a domain with no evident connection to the repository or its GitHub Pages site — most likely just where the developer hosts the build, but worth knowing before you put an original design into it. Nothing is said either way about analytics.

ComposeYogi

An Ableton-shaped studio that installs to the home screen · iPad, Mac

What it is. A composition tool in a browser tab: multi-track timeline, piano roll, drum sequencer, mixer, 64 instruments through Tone.js, and recording with latency calibration. It exports WAV, MP3, MIDI and a portable JSON project file, and it is a progressive web app — the README says it installs and works offline.

Why it is for you. The iPad is where the ideas and the sketching happen and it cannot run Claude Code, so the things that reach it have to be browser apps; this is one that installs to the home screen and then works with no connection. The export list is what makes it more than a toy: MIDI out means eight bars worked out on the sofa comes back as a file you can open in Reaper and orchestrate properly, which is the same route your Python MIDI work takes, from the other end. It was on the radar on 18 October and is promoted now because the offline-install claim is precisely the thing that makes it useful to you rather than generically interesting.

To try it. Open the hosted app, add it to the home screen, put down eight bars, export the MIDI and open it in Reaper — that round trip is the whole test. No account. If you want it local it is git clone, npm install, npm run dev on Node 18.17 or later: ordinary npm, no shell pipe, no sudo. There are Docker images too, which are no use on an ARM NAS that cannot run Docker. About 45 minutes.

Risk. MIT, stated plainly. Created 10 January 2026, so about nine and a half months old, 152 stars against 14 forks, with one organisation behind it rather than a crowd. The README never explicitly says all the audio stays in the browser: it names Web Audio, WebAssembly and Tone.js and says projects are stored locally in IndexedDB, which together make a server round-trip unlikely, but that is inference, and it takes no position at all on analytics. IndexedDB is also the entire persistence story, so clearing site data on the iPad would take your projects with it — export anything worth keeping rather than trusting the tab. And latency calibration being a named feature is a fair warning in itself: recording live through a browser on a tablet is fiddly, whoever builds it.

Chromatone

Music theory you can see, as colour · browser, iPad

What it is. A long-running research project that maps the twelve pitches to twelve hues thirty degrees apart, and builds things on top of that mapping: a set of browser instruments, and cards and overviews on harmony, rhythm and the physics and physiology of hearing and seeing. It also publishes two npm packages — a sound analysis and synthesis layer, and a music database of intervals, chords, scales and rhythmic patterns from several cultures, held as YAML.

Why it is for you. It lands on two interests at once. A consistent pitch-to-colour mapping is one of the few honest ways to show a small child what a chord is without notation having to be taught first — which is the standing problem in making music games for children, where the notation is usually the obstacle rather than the subject. And the YAML database is the part a builder should look at hardest: scales, intervals and rhythmic patterns as structured data you can read straight into a game is material you would otherwise type out by hand. For your own listening the theory cards are a side door into the critical-bands and dissonance reading you have already done.

To try it. Open the site and work through the Practice section's instruments; twenty minutes is enough to judge whether the colour mapping actually teaches or merely decorates. Nothing to install and no account; the only build route offered is a Codesandbox fork. If a tool earns it, the npm packages drop into a project of yours directly.

Risk. MIT by GitHub's reading, but the README never names a licence in text — read the licence file before lifting that database into anything of your own. Five and a half years old and committed to this month, 151 stars, 12 forks. The real risk is who is behind it: the README is written in the first person by a single unnamed maintainer and calls itself a research project and a digital garden, so expect some of it to be unfinished and some of it to be someone thinking aloud. It describes the practice tools as progressive web apps but never claims offline support, names no devices or browsers at all, and says nothing about analytics. The npm packages are the dependable part; the site is the shop window.

For your projects

Aimed squarely at the video pipeline — and this one is both: something to use and something to learn from.

riso-windowseat

Procedural films as single HTML files, with the render harness included · Mac

What it is. Nine procedural "risograph" films and two print series, each film a single self-contained index.html drawn with Canvas 2D and sounded with Web Audio — no libraries, no fonts, no images and no network calls. Shipped alongside them are the Claude Code skills and the render harness that made them: Playwright plus a bundled ffmpeg, exporting stills, contact sheets and 1080×1080 30fps MP4s.

Why it is for you. This is your own video pipeline, built by somebody else and handed over with its working parts visible. You record HTML scenes with Playwright and ffmpeg; this is the same architecture with the quality gates actually filled in, which is the part that is tedious to invent twice. Two specifics earn the visit whether or not you use a line of the code. The first is a hook that runs after any film edit and fails it for calling Math.random() — that is determinism enforced mechanically, and it is the thing that makes a render reproducible and two renders comparable, which is a problem your pipeline has to solve too. The second is that the soundtrack is treated as code rather than as an asset to drop in. The single-file constraint is also a straight answer to serving scenes off GitHub Pages.

To try it. Watch first: open a film at the hosted gallery and press Play, with the sound toggle on — audio starts off. Ten minutes. To read the machinery, git clone it, then in tools/ run npm install && npm run setup && npm test on Node 18 or later. Plain npm, no shell pipe, no sudo. Note that npm run setup downloads Chromium and Firefox builds, so expect a few hundred megabytes — the size is nowhere stated. About an hour to read the three skills properly, which is the real value here.

Risk. The licences are mixed, and that matters the moment you reuse any of it. MIT for the code, the films and the prints — but one film's piano recordings are CC BY 3.0 and the attribution has to travel with them, another's wing geometry derives from a Wikimedia image under CC BY-SA 4.0 and is offered under that licence, and the remaining sampled recordings are CC0. The code is clean to borrow; the media is not uniformly so. At five weeks old this is the youngest thing in the issue and only just past the line this newsletter draws, with 304 stars against 32 forks. No individual maintainer is named, and the README says the author directed each work while Claude Code wrote the code — so read it as one person's output, not a team's, and the hooks and self-tests as the reason to take it seriously anyway. The tooling needs Claude Code and the README does not say what access that assumes. One telling detail: the released MP4s are Firefox renders rather than Chromium, which suggests the two do not render identically. macOS is never claimed, though a Node, Playwright and ffmpeg stack has no obvious reason to struggle there.

A game

Two players, one device, and a Klein bottle.

Topology Gomoku

Five in a row, on surfaces that wrap · browser, iPad

What it is. Five-in-a-row where the board's edges join up. Seven worlds take you from a flat grid through a cylinder, a Möbius strip, a torus, a Klein bottle, the real projective plane and a sphere, so a line can leave one edge and reappear somewhere thoroughly counter-intuitive — which is the entire game. There are three local AI difficulties, a two-player mode on one device, a "boundary demo" that draws each world's winning routes, and a 3D sphere view when you win. It says it runs fully offline, with no accounts, no ads and no network requests.

Why it is for you. Board games and mathematics in one tab, and the rare case of a game that teaches something true rather than wrapping a quiz in a theme: a Klein bottle stops being a definition the first time a win arrives from a direction you did not know existed. The two-players-on-one-device mode is the point for an evening at home — five-in-a-row is a game a young child can already play, so the wrapping boards become a way to show what topology means before anyone has to write the word down. And the boundary demo matters pedagogically: you can look up why a line counted instead of arguing about it.

To try it. Open the hosted version, play the flat board once to settle the controls, then the cylinder. Progress saves on the device and new worlds unlock as you win. Fifteen minutes, no install, no account.

Risk. MIT, confirmed in the repository's own licence metadata rather than only in prose. The numbers are the thinnest here by a distance — 16 stars, 4 forks, created 27 August 2026, one developer — so treat it as an evening's curiosity and not as something to rely on. The project is Chinese-language throughout, README included; the game itself is mostly a board and symbols, but expect menus you have to guess at. A plain fetch of the hosted page returned nothing readable, which is ordinary for a JavaScript app but does mean nobody has actually confirmed to you that it loads — if it does not, that is the end of it, because the other routes the README lists are a WeChat mini-program and entries on Chinese social platforms, none of which are worth the trouble. The "no network requests" claim is the project's own and was not verified.
