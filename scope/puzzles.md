# Puzzle Weekly — scope

**This file defines what the newsletter covers.** The weekly task reads it at the start of
every run and treats it as authoritative. To change the newsletter, edit this file — you do
not need to touch the scheduled task's prompt.

## Subject

A weekly roundup of Andrew's favourite kinds of puzzle, timed to land Friday morning so there's
a stack of them for the weekend. **Word puzzles (crosswords, anagrams, word searches, Wordle-
likes) are explicitly out of scope** — Andrew isn't a fan, don't include them even if they're
popular or easy to source.

## Sections to cover

1. **Sudoku variants** (the main event) — 2–3 puzzles in the "Cracking the Cryptic" style:
   killer, thermo, arrow, sandwich, XV, renban, German whispers, or any other constraint-layer
   variant on top of standard sudoku. Source from sudokupad.app / app.crackingthecryptic.com
   (CTC's own puzzle host — links found via their YouTube video descriptions or the site's own
   new-puzzle listings) or f-puzzles.com. Every puzzle needs a real, working "play it" link
   (sudokupad.app links are ideal — playable in-browser, no app required) and a one-line plain-
   English explanation of its special rule(s) for anyone who forgets between issues. Note the
   setter/source and roughly how hard it is if that's discoverable.
2. **LinkedIn daily games** — Queens, Tango, Zip, Crossclimb, Pinpoint, Mini Sudoku, etc. These
   reset daily, so don't try to link a single day's exact puzzle — instead pick 2–3 of the
   games worth a shout this week (e.g. one that's been extra tricky, or a personal favourite
   worth doing daily), link to https://www.linkedin.com/games/ , and say why they're worth a
   coffee-break.
3. **Thinky Games dailies** — link to https://www.thinkygames.com/daily-puzzles and highlight
   2–3 specific titles from their lineup worth trying that week.
4. **Maths puzzle of the week** — Andrew likes the maths puzzles that turn up on his Facebook
   feed, but that feed isn't something Claude can read. Substitute: search out one genuinely
   good, well-known maths/logic puzzle from a reputable source (Presh Talwalkar /
   MindYourDecisions, Brilliant.org, Futility Closet, or similar) each week — same flavour, not
   literally the same posts. Give the puzzle itself (or a clear teaser) plus a link to work
   through/reveal the answer, without spoiling it in the newsletter text.

## Rating — how it feeds back in

Each puzzle/section has 👍 / 🙂 / 👎 one-click links that log straight to a Google Sheet (no
page to fill in). Before writing each week's issue, fetch the ratings summary (URL in the
scheduled task prompt) and use it to shift emphasis for **next** week — more of what's rated
well, less/none of what isn't, by category/style/difficulty (e.g. "killer sudokus keep getting
👍, thermo doesn't — lean killer/arrow"). It can't fetch you the literal same puzzle again since
these are one-off dailies; it's steering the *kind* of puzzle picked, not a repeat.
