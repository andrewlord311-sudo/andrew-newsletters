# What's On — scope

**This file defines what the newsletter covers.** The weekly task reads it at the start of
every run and treats it as authoritative. To change the newsletter, edit this file — you do
not need to touch the scheduled task's prompt.

## Subject

Local activities for the coming week in Colchester / Essex.

## Sections to cover

Prioritise things happening in the next ~7–10 days over things further out, and always prefer
genuinely current listings over generic evergreen attraction pages.

1. **Pick of the week** — the single most notable thing on (a play, a one-off event). Must
   always have a real source link.
2. **Open days** — garden open days (National Garden Scheme etc.), heritage/venue open days,
   anywhere normally closed opening to the public.
3. **Kids' events** — school holiday clubs, museum trails, family workshops.
4. **Food and drink** — festivals, markets, pop-ups. If nothing new is on, fall back to a
   standing option (e.g. the regular town market) and say so honestly.
5. **Museums and exhibitions** — new/current shows at Colchester Castle, Firstsite,
   Hollytrees, Natural History Museum, or similar local venues.
6. **This week at a glance** — summary table.

## Standing preferences

- Never invent facts, dates, prices, or links — every listing must come from an actual search
  result with a real URL.
- Always include the date/time and a link for each listing; include price where findable.
- If a category turns up nothing for the coming week, say so plainly in a warn-callout rather
  than padding with stale content.
- Anything already finished by the time of sending must not appear as upcoming.
